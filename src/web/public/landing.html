把杂乱的写作拆成可工作的流程

写一篇有结构的长文，难的不是把字凑够，而是把"想说的"先想清楚。LucidWrite 把这件事拆成了七个阶段，每一步只做一件事。

选题阶段不写一个字，只问问题。大纲阶段不写段落，只画结构。

PROCESS

七步流程，每一步都有专门的 agent。

选题不收敛就不进入大纲。大纲不通过就不开始初稿。卡在哪一步，就停在哪一步，直到这一步真的可以交付。

  1. 01选题交互

    把模糊的想法磨成可写的角度

    不限轮次的选题对话，最多 3 轮收敛。AI 会反问，把"想写点什么"逼成"具体写什么"。

  2. 02大纲框架

    把选题拆成可执行的结构

    基于已确认的选题生成大纲。直接修改，或要求 AI 协助调整。结构不通过，不进入初稿。

  3. 03初稿敲定

    基于大纲一气呵成

    从结构到文字。右侧聊天可以随时改左侧草稿，AI 每次返回完整版本，不做局部 patch。

  4. 04内容精修

    系统先给出精修报告

    逻辑断点、表述冗余、段落节奏。先列清单，再决定改哪些。不喜欢的改动，直接驳回。

  5. 05事实核查

    引用、数据、人名地点逐一对照

    独立的核查阶段。AI 不会替你判断"应该是这样"，而是把每一处可疑的地方挑出来给你看。

  6. 06质量评分

    对全文打分，合格再进终稿

    多维度评分。合格自动进入终稿；不合格也可以手动强推，但你会知道自己绕开了哪一关。

  7. 07终稿敲定

    final.md 输出，draft.md 留作工作稿

    最后微调后保存 final.md。原始草稿继续保留，所有改动都在你的目录下，可以直接 git diff。

  8. ∞loop

    任意一步都能回头

    核查阶段发现选题立不住，可以回 01。质量评分不过，可以回 04。流程是顺序的，不是单向的。

AI 替你写完一篇文章很容易。
难的是，它不替你想清楚你要写什么。
— Why LucidWrite exists

WHY LUCIDWRITE

不是另一个"AI 帮你写一篇"的工具。

LucidWrite 假设你想自己写，只是需要一个能拆解工作流、记得上下文、不会把控制权抢走的工作台。

多 agent 调度

选题、采访、写作、核查、评分各司其职。每一阶段调度对应能力，不是一个万能 prompt 走到底。

本地工作区

草稿、终稿、附件都在你指定的目录下。Markdown 文件可见可控，可以直接 git commit 或外部编辑。

风格指纹

导入 1-5 篇历史文章，LucidWrite 学一次，长期沿用你的语气、节奏、用词。不需要每次重新喂例子。

LLM 可换

DeepSeek、OpenAI、Anthropic、Google，任何 OpenAI 兼容的端点都行。模型决策权留给你，不绑定。

UNDER THE HOOD

本地启动，云端同步，Markdown 输出。

Runtime Bun · Hono 浏览器访问本地端口，服务端只跑在你机器上。
Storage Supabase · Row-Level Security 账号、项目、草稿、风格指纹云端同步，每个用户只看得到自己的数据。
Models DeepSeek · OpenAI · Compatible 在设置里填 API key，或走 .env。模型怎么选，你说了算。

FAQ

常见问题。

我的写作数据存在哪里?
Markdown 文件(draft.md / final.md / references)在你本地的工作目录下，可以直接 git 管理。项目元信息、风格指纹、账号通过 Supabase 同步到云端，每个用户走 Row-Level Security，只看得到自己的数据。
能完全离线用吗?
本地服务跑在你机器上，但调用 LLM 需要联网。如果接入本地模型(Ollama 之类的 OpenAI 兼容端点)，就可以真正离线。
可以换 Claude / GPT-4 / 别的模型吗?
可以。设置里填 API key，或走 .env。任何 OpenAI 兼容的端点都行 —— DeepSeek、OpenAI、Anthropic、Google、Together、本地推理服务等。
写到一半能换模型吗?
能。每一阶段独立调用，可以选题用便宜模型，核查换强模型。流程不会因为换模型断掉，因为上下文都从你的 draft.md 和聊天记录读回来。
风格指纹会泄露我的原文吗?
风格指纹是抽象后的摘要(语气、节奏、用词偏好等)，不存原文。导入历史文章时原文也只在生成指纹的那次请求里送给模型，生成完不留底。
需要会写代码吗?
安装一次要会跑两条命令(bun install 和 bun run web)。之后日常用就是浏览器，跟用别的网页工具没区别。
