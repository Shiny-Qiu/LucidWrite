# 中央富文本编辑器

2026-09-07：参考本机 OpenMAIC / DeepTutor 智能写作中的 RichMarkdownEditor、DocumentChrome、DocumentBlockGutter 和 DocumentTableControls，实现适合 LucidWrite 现有三栏工作区的文档编辑交互。

## 使用

- 顶部工具栏：段落与六级标题、字体和字号、加粗、斜体、下划线、删除线、文字颜色、高亮、对齐及撤销重做。窄编辑区的字体、字号等放在“更多”菜单中。
- 选中文字：浮动工具栏保留选区，可格式化、插入链接，或作为引用发送到右侧 AI 输入区。
- 空段落输入 `/`：搜索并插入正文、标题、列表、待办、引用、高亮块、代码、表格、图片、链接、分隔线、折叠块及分栏。支持方向键、Enter、Escape，避开中文输入法确认键。
- 段落左侧：加号插入内容；六点按钮打开复制、上下移动、删除等操作，也可拖动内容块调整顺序。删除和移动可以撤销。
- 表格：选中单元格后显示行列增删、合并与拆分、表头工具；可拖动列边界调整宽度。
- 图片：网址、上传、粘贴及拖入；选中后设置宽度或删除。上传的位图压缩后随文章保存；GIF 上传会转为静态图片。
- 更多：行内代码、上下标、列表缩进、清除格式、查找替换、导入 Markdown/HTML/文本、复制全文、导出 Markdown/HTML/纯文本、打印/PDF。
- 底部：文章目录、字数与选区字数、缩放、全屏。快捷键使用系统的 Cmd 或 Ctrl：S 保存，F 查找，K 链接，Z 撤销。

## 存储及现有流程

编辑器由 Tiptap 3 提供文档模型，源码位于 `src/web/editor`。`build:editor` 使用 esbuild 生成浏览器脚本，开发、网页测试、CLI 构建和 Vercel 构建均接入此步骤。

未编辑时保留原始 Markdown。编辑后普通段落仍存 Markdown；颜色、下划线、表格、折叠、分栏、代码等需要保真的节点存为 schema 生成的 HTML，重新打开由同一 schema 解析。代码采用 HTML 保留嵌套反引号。富文本粘贴使用 DOMPurify 清理脚本、事件属性和不安全链接。

工作稿继续使用原来的自动保存、版本冲突检测、离开前提示和本机恢复副本。不同项目之间清空撤销历史。终稿使用独立只读编辑器展示，可以查找、复制和导出。数据库结构、DeepSeek V4 Pro 配置和七阶段写作流程不变。

图片上传、文档导入在异步读取后核对项目与文档版本；过期操作不会写入其他文章。导入前检查合并后的序列化文档容量，超限保留原文。嵌入图片在发送给 AI 前转换为稳定引用，返回结果再还原，避免把 base64 图片字节塞入文本模型上下文。

本次实现中央文档编辑。多人实时协作、云端评论与权限共享不在当前编辑器范围内，界面没有这些能力的占位按钮。
